# Klinikum Chronicles

Browser-JRPG im Krankenhaussetting.

## Stable release

`main` ist die stabile, über GitHub Pages veröffentlichte Version.

## Roguelite v2 development

Die größere Weiterentwicklung erfolgt auf `feature/roguelite-v2`.

Leitidee: **JRPG-Kern beibehalten, Roguelite-Struktur darum bauen.**

Core Loop:

`Olivias Wohnung -> Schicht -> Räume / Events -> JRPG-Kämpfe -> Boss -> Wohnung`

Der erste Entwicklungs-Shell liegt in `dev-v2.html`. Architekturdetails stehen in `docs/ROGUELITE_V2_ARCHITECTURE.md`.

Wichtig: Änderungen auf dem v2-Branch werden erst nach einem getesteten Meilenstein nach `main` übernommen.
